Publication status

These instructions describe accessing XYZ.HUB through Discord on mobile. They do not announce a standalone XYZ.HUB iOS or Android app.

Before you start

Open the Discord account you intend to use with XYZ.HUB.

Use the approved XYZ.HUB entry instructions or invitation supplied by the project.

Check project updates from @_xyzhub_.

Review the app identity and requested permissions before approving access.

Do not send anyone your Discord password, authentication codes, or access tokens.

iPhone walkthrough

Open Discord on your iPhone.

Check that you are signed into the intended Discord account.

Follow [APPROVED_ENTRY_LINK] or open the approved XYZ.HUB destination.

Complete any existing server-entry requirements shown by Discord. This walkthrough does not replace the already integrated server onboarding.

Open the permitted text channel or voice call identified in the project instructions.

Open Discord's App Launcher, select the verified XYZ.HUB application, and choose Launch where shown.

If Discord requests authorization, check the application identity and requested permissions. Continue only if you recognize and trust the application.

Return to the Activity and wait for the application to finish signing you in.

If the build includes a membership-status view, read that status separately from the sign-in result.

Until independently verified, treat real Member-grant availability as pending.

Discord documents a mobile App Launcher beside the chat bar and an App Launcher in voice calls; first-time users may need to authorize the selected Activity. Exact presentation should be checked on the tested Discord version.

Android walkthrough

Open Discord on your Android phone.

Check that the selected account is the one you intend to use with XYZ.HUB.

Follow [APPROVED_ENTRY_LINK] or open the approved XYZ.HUB destination.

Complete any existing server-entry requirements shown by Discord.

Open the permitted text channel or voice call identified in the project instructions.

Open the App Launcher and select the verified XYZ.HUB application.

Choose Launch where shown.

Review any Discord authorization request before continuing.

Wait for the Activity to finish signing you in.

Check any available membership-status view separately. A successful sign-in does not establish Member-grant availability.

The Discord mobile launch pattern applies to Android as well; XYZ.HUB's actual labels, loading behavior, and supported devices still require testing.

If onboarding stops

Authorization canceled: reopen the Activity when ready and review the request again.

Activity missing: use the approved project instructions; ask support to check app access and platform configuration.

Sign-in fails: follow the OAuth recovery guide.

Member access missing: do not repeatedly authorize. Report the membership state separately.

Wrong account selected: stop before continuing; switch to the intended Discord account and start again.
