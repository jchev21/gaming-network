Terminology

Discord authorization: permission for the application to access the approved Discord scopes.

Application authentication: establishing the user's identity/session after authorization.

Member grant: the project-specific Member entitlement or role assignment. Its implementation and availability are unverified.

Discord installation: adding an application in an allowed user or server context.

Game host: the person creating a game session; this does not imply their phone runs the backend.

These are separate states. Never treat “authorized,” “installed,” “authenticated,” or “game joined” as proof that a Member grant exists.
