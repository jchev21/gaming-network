# Source inventory — repository review port

This isolated folder contains:

- `index.html`: offline in-person launch acceptance page
- `styles.css`: dark/violet, responsive layout
- `checklist-data.js`: 20 required checks in six categories
- `console-core.js`: state schema, import/export, validation, manual signoff gate
- `app.js`: local UI, localStorage, downloadable JSON + Markdown
- `test-console.mjs`: deterministic Node tests
- `HANDOFF.md`: operating and safety guidance
- `MANIFEST.md`: this inventory
- `QA-RESULTS.txt`: verification record

This is a GitHub source port of the Perplexity ZIP, not a claim that the GitHub files are byte-for-byte the delivered originals. SHA-256 inventory in the original ZIP applies only to original extracted ZIP files.
